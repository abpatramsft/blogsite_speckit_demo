# Blog Favicon

This folder contains the site favicon and app icons.

## Current Files

- `favicon.svg` - SVG favicon with "B" letter
- `favicon.ico` - Will be generated from SVG (optional)

## To Add Custom Icons

Replace the files with your own:
1. **favicon.svg**: 100x100px SVG icon (recommended)
2. **favicon.ico**: Multi-resolution ICO file for older browsers
3. **apple-touch-icon.png**: 180x180px PNG for iOS devices
4. **icon-192.png**: 192x192px PNG for Android
5. **icon-512.png**: 512x512px PNG for Android

## Quick Generation

Use tools like:
- https://realfavicongenerator.net/
- https://favicon.io/

Upload your logo and generate all required formats.
